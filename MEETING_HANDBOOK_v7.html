06如果先做 APP

APP 是 consumer-product benchmark，不是低配 API

变量控制方式
账号每产品独立研究账号，不用个人长期账号
Memory / history能关则关；不能关记录 not controllable
Custom instructions留空
上下文每题新会话，只发 frozen prompt
Thinking / search / tools冻结可见设置并记录默认状态
顺序固定 seed，按产品随机化/区组随机
Quota / fallback额度耗尽、自动降级、429 必须记录
研究者行为不追问、不 regenerate、不点赞点踩
保存raw text + screenshot + timestamp + manifest
隐藏 system prompt、安全层、routing 控制不了，也无需假装控制；它们本来就是产品的一部分。APP 与 API 可以共享 case/rubric/schema，但必须作为不同 evaluation strata 解释。

08案例来源

不是四选一，而是不同来源负责不同层

来源适合贡献不能承担
Existing benchmarkanchor / coverage / 方法参考不宜直接成为主体题库；需查 license/contamination
临床医生ontology、边界、severity、最终 approve/reject不必机械从零写 160 句
AI按 blueprint 合成、minimal pairs、语言变体、confound check不能定义 clinical truth
教材/casebook/论文phenomenology、blueprint、differential clues不大段照搬，不把真实个案伪装成 fictional
文学/回忆录语言肌理、隐晦表达、文化语境不能作为诊断 gold standard
