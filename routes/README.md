# PAIR Routes — parallel execution map

The project is now intentionally advanced in **three parallel routes**. This does not mean all three should be run as full studies. It means each route is developed far enough that the team can compare real protocols rather than abstract ideas.

## Current route state

| Route | Scientific question | Ready state | Main blocker |
|---|---|---|---|
| A | Are psychosis prompts answered less appropriately than matched controls, and do consumer products differ? | protocol/SAP structure ready | full prompt set + clinician approval |
| B | A + does a model shift response policy appropriately when one clinically important cue changes? | Aim 1 + pilot specification ready | clinician action thresholds + pilot approval |
| C | Where are psychosis-specific response-policy boundaries under minimal clinical cue changes? | benchmark specification ready | formal novelty review + clinician ground truth + team approval |

## Important result boundary

No empirical model-performance result exists yet. Any document under `routes/` called a result/template/dry-run is **design-level or synthetic pipeline validation only**. It must never be cited as observed clinical/model evidence.

## Current methodological recommendation

**B > A > C for the present collaboration.**

- A is the fastest and safest publication route.
- B preserves A and adds a bounded scientific contribution.
- C remains interesting, but 2026 literature has moved quickly; broad counterfactual mental-health auditing is already occupied, so C must use a narrower psychosis-specific signature.

See `ROUTE_COMPARISON.md` for the decision matrix.
