PAIR 的主目标不是把 A、B、C 做成三个平行实验，而是逐步构建一套可复用的精神病性回应 Benchmark。

A、B、C 对应三个逐渐深入的问题：A 先确认“精神病性内容是否更容易触发不恰当回应”；B 再问“当关键临床信息变化时，模型会不会调整回应”；C 最后把这种调整能力系统化成可复用、可扩展、可跨模型比较的测量框架。

A 是现实世界基线；B 是从普通审计走向“可控临床对照”的桥梁；C 是 PAIR Benchmark 的方法学核心试点。

A：先建立现实世界基线——问题存在吗？

A 保留原 protocol 的核心结构：80 条精神病性相关提示词 + 80 条严格匹配对照，按 SIPS P1–P5 五个领域平衡，每个领域 16 对。这里的“80 对”主要来自原项目设计和领域平衡，并不是一个重新通过功效分析推导出的唯一最优数字。

A 不设置 conviction、insight、risk 等“轴”。它只问一个最基础的实验对照：在主题、语气、行为要求尽量相同的情况下，精神病性相关成分本身是否增加不恰当回应的风险？

为什么用约 5 个消费产品？因为 A 的对象是普通用户真实接触到的产品生态，需要一定覆盖面；同时每增加一个产品都会新增完整的人工采集、截图、版本记录和医生评分工作量。因此 5 个左右是“市场覆盖 × 可执行性”的平衡，而不是统计学规定必须恰好 5 个。

B：加入最小临床对照——模型到底读懂了哪些信息？

B 不替代 A，而是在第一篇中加入一个有边界的探索性子研究。它第一次把普通“病例”变成 场景家族 × 临床轴 × 两个水平 的可控实验单元。

轴为什么进入第一轮预期的临床含义
确信程度（conviction）直接反映异常解释的确定程度，比较容易形成低/高最小对照确信更高时，通常更需要澄清、现实检验和避免强化
对其他解释的接受程度（insight）能够区分“有异常体验但仍能保留替代解释”与“完全丧失替代解释”insight 降低时，回应通常需要更加谨慎地评估影响和专业帮助需求
即时行为风险最直接决定回应是否需要从支持性交流升级到风险评估或紧急处理风险增加时，回应强度应有明确上调方向

为什么 B 只有 3 个轴？因为它是桥梁试验，目标是先验证“单一临床变量最小改变”这种测量方法是否可行。文化、病程、功能损害、物质使用、药物、证据合理性等都可能重要，但全部加入会让第一篇迅速膨胀成独立 benchmark。

为什么是 6 个场景家族？每个家族需要 3 个轴 × 2 个水平 = 6 条提示词，因此 6 个家族就是 36 条提示词。再用 3 个代表性消费产品、每题 3 次生成，共 324 条回应。这个规模是有意压小的 pilot：足以测试医生能否稳定判断、模型是否出现可解释的方向信号，又不至于拖垮第一篇。如果表现良好，B 的场景家族可以扩展到 15–20 个。

为什么先测 3 个产品？B 的主要目的不是重新做一次市场排名，而是测试方法。因此只需要一个预先冻结、具有代表性的产品子集。最终选择规则必须在看 A 的结果之前冻结，避免“看谁最有趣再挑谁”。

C：把方法独立成 Benchmark——能否系统测量“临床回应校准”？

C 不再只是第一篇的附加分析，而是 PAIR Benchmark 的 benchmark-development pilot。它的研究对象从“哪个产品更好”转向：当一个临床关键信息改变时，模型是否在正确方向、以合适强度改变回应策略，同时避免回应不足和过度升级。

C 在 B 的三个轴上增加第 4 个轴：证据/普通解释的合理性（evidence/plausibility）。这个轴更复杂，因为证据增加并不总是意味着“升级更多”，有时应该降低病理化程度、维持不确定性或保持回应强度不变。因此它更适合放在独立方法学研究，而不是第一篇的探索项。

为什么 C pilot 是 8 个场景、3 个配置，而不是更多？

8 个 family 不是理论上“最正确”的数字，而是 benchmark-development pilot 的工作量折中。它让每个轴都能在多个不同精神病性表型中重复出现，避免某个“轴效应”其实只是某一条故事造成；同时又小到临床专家可以逐条检查 manipulation success、混杂和可接受回应区间。

3 个固定 API 配置同样主要服务于验证测量工具，而不是覆盖整个市场。此阶段最重要的是模型版本可识别、参数可固定、结果可重复。正式 benchmark release 再扩大模型覆盖面。

为什么现在只有两个水平？

两水平设计适合先回答：临床信息从低变高后，模型有没有沿正确方向变化？ 但它不能精确告诉我们“真正的临床阈值在哪里”。如果 pilot 证明轴和指标稳定，正式版应对关键轴增加 3 个或更多有序水平，才能进一步研究模型跨越某个干预阈值的位置是否与医生一致。

PAIR Benchmark 最终想形成什么？

Ontology

哪些精神病性场景、哪些临床变量、哪些上下文属于 benchmark 的测量空间。

Scenario families

同一基础情境下，只改变一个临床 cue 的版本化病例家族。

Clinician ground truth

可接受回应强度区间、目标变化方向、禁忌行为和原始医生分歧。

Metrics

总体校准、方向一致性、回应不足、过度回应、随机稳定性和未来的阈值校准。

项目主次关系：PAIR Benchmark 是长期资产；A+B 与 PAIR-C 是第一阶段验证论文。以后新模型、新版本或新的安全干预方法，都可以重新在同一 benchmark 上测试，而不必重新发明评价标准。
仍需在真实采集前冻结：B 三个消费产品的预先选择规则；C 三个 API 配置的正式 sampling rationale；关键轴未来扩展到 ≥3 levels 的触发条件。这些目前属于设计决策，而不是已经被数据证明的最佳选择。
