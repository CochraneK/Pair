# PAIR meeting narrative — original student protocol → A+B / PAIR-C

## 中文

### 一句话原则
不要把升级说成“推翻学生方案”。原始 matched-prompt 主问题应被明确认定为第一篇论文最稳的核心；所有增强都从 Reviewer #2 可能提出的问题出发。

### 建议开场
“我没有想把原来的方案推翻。原来最重要的 matched psychosis vs control 设计我觉得应该保留，而且它其实是这项研究最稳的一部分。我们后来做的工作，主要是把产品版本、匹配质量、重复稳定性、统计主模型和临床边界这些容易被审稿人追问的地方补齐。补到后面发现，有一部分增强可以嵌在原研究里，有一部分已经足够成为第二篇独立方法学论文，所以现在才形成 A+B 和 C。”

### 原始方案应保留的核心
- 80 psychosis-related prompts，SIPS P1–P5 各 16。
- 80 matched nonpsychotic controls。
- 多个中文消费级 AI 产品。
- 2 名精神科医生评分。
- 0/1/2 appropriateness 及 recognition / non-reinforcement / urgency / resources。
- repeat subset。
- ordinal / clustered analysis 思路。

### Reviewer-style 增强链
1. “只是中文 replication 吗？” → A 保守定位，B 增加机制，C 独立。
2. “模型还是 APP？” → consumer-product snapshot + SOP + version freeze。
3. “controls 真匹配吗？” → pair audit + P5 sensitivity。
4. “哪个统计模型 primary？” → freeze one ordinal primary framework。
5. “越升级越安全吗？” → `[L,U]` + URS/ORS。
6. “一次回答代表模型吗？” → stratified repeats / 3-run stochasticity。

### 最终分化
- Paper 1 = A primary + B exploratory.
- Paper 2 = PAIR-C independent calibration / benchmark-development pilot.

### 会议叙事顺序
原始方案 → 已有优点 → 审稿人攻击点 → 最小改进 → 两篇论文 → 对话例子 → 模拟图 → 论文全文 → 现实拍板事项。

## English

### One-line principle
Do not frame the upgrade as replacing the student protocol. The original matched-prompt question remains the most stable core of Paper 1; every enhancement should be justified as a response to a plausible reviewer concern.

### Suggested opening
“I do not think the original study should be replaced. Its matched psychosis-versus-control question is still the most stable part of the project. We first preserved that core, then looked at the places a reviewer would likely challenge: product identity, pair quality, repeat stability, the primary statistical model, and whether stronger intervention is always better. Some improvements fit naturally inside the original paper; one line became strong enough to justify a separate methods paper. That is how A+B and C emerged.”

### Original elements to preserve
- 80 psychosis-related prompts, 16 each across SIPS P1–P5.
- 80 matched nonpsychotic controls.
- Multiple Chinese consumer AI products.
- Two psychiatrist raters.
- 0/1/2 appropriateness plus recognition, non-reinforcement, urgency, and resources.
- A repeat subset.
- Ordinal / clustered analysis logic.

### Reviewer-driven enhancement chain
1. “Is this only a Chinese replication?” → conservative A, mechanism-oriented B, independent C.
2. “Model or consumer app?” → product-snapshot claims, SOP, version freeze.
3. “Are controls truly matched?” → pair audit + P5 sensitivity analysis.
4. “Which model is primary?” → one frozen ordinal primary framework.
5. “Is more escalation always safer?” → `[L,U]`, URS, ORS.
6. “Does one generation represent the system?” → stratified repeats / repeated stochastic runs.

### Final split
- Paper 1 = A primary + B exploratory.
- Paper 2 = PAIR-C independent calibration / benchmark-development pilot.

### Meeting narrative order
Original protocol → strengths → reviewer attacks → minimal upgrades → two papers → dialogue examples → simulated figures → full manuscripts → real-world decisions.
