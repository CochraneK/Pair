01两篇论文

现在不是 A / B / C 三选一，而是两篇不同层级的论文。

Paper 1｜A + B

主问题仍然很朴素：当精神病性内容出现时，消费级 AI 是否比面对严格匹配的普通问题更容易回应不当？B 只是嵌套进去，问临床 cue 改变时回应策略会不会跟着变。

Paper 2｜PAIR-C

不再做“谁分数最高”的 benchmark。它研究的是：只改变一个临床信息时，模型的干预强度是否沿医生要求的方向移动，同时避免回应不足与过度病理化。

真正有价值的 C，不是把模型排个名，而是找到“模型在什么临床信息上不敏感、又在什么地方反应过头”。

02A+B 要回答什么

A 的故事应该保持简单；B 负责解释“平均安全”为什么还不够。

A 的 primary story 是 matched psychosis vs control。产品差异、P1–P5、failure profile、稳定性都属于解释层。B 只有 6 个 family，所以必须坚持 exploratory，不把 324 次调用假装成 324 个独立临床案例。

模拟演练：精神病性提示词相较匹配对照的配对风险差。真实论文主分析仍应使用预注册的 ordinal mixed model。

03C 为什么值得单独做

因为“落在可接受区间”与“临床信息变化时会正确改变”不是一回事。

模拟演练：横轴是 interval calibration，纵轴是 cue-direction concordance。两者可以明显分离。
模拟演练：回应不足和回应过度分别测量。两个 CCA 接近的模型，错误方向可能完全不同。

04模拟数据

模拟的目的不是预测谁强，而是验证“论文能不能被数据讲清楚”。

轨道模拟结果所展示的论文逻辑不能做的解释
Apsychosis prompt 相对 matched control 出现稳定的 appropriateness penalty不能说任何产品现实中真的有这个表现
BCCA 可以较高，但 directional concordance 只有约七成不能把工程 `[L,U]` 当医生 ground truth
C不同配置在 URS/ORS 与 axis sensitivity 上形成不同 failure signature不能说已经验证了完整 benchmark
模拟演练：A 的完整评分分布比单一平均分更适合正文展示。
模拟演练：C 的价值应该落实到轴别差异，而不是只剩一个总分。

05真实采集前

现在真正缺的是现实世界证据，不再是更多文字。

  • 真实伦理/研究属性认定。
  • 正式 preregistration 或透明说明未注册。
  • A/B 消费级产品版本、账户、搜索/思考/记忆状态冻结。
  • B/C 的真实医生 `[L,U]`、target direction、manipulation success 与 confound review。
  • 真实 response raters，以及裁决前一致性。
  • C 的固定 API model/config manifest。
  • 真实分析完成后重新生成图表、Results、Discussion，再做一次 Reviewer #2。

06会上拍板

建议会议只决定四件事情。

1｜产品集合

A 的 5 个消费级产品是否就是最终 sampling frame？

2｜医生审核

谁负责题目 validation，谁负责输出 rating，是否尽量分开？

3｜C 的定位

是否认可它是 pilot benchmark-development paper，而不是一次就做成“终极 benchmark”？

4｜采集窗口

什么时候完成产品快照和真实 smoke pilot？

01Two papers

This is no longer a choice among A, B, and C.

Paper 1 | A + B

Do consumer AI products respond less appropriately to psychosis-related content than to tightly matched ordinary controls? B is nested as an exploratory test of cue-contingent policy change.

Paper 2 | PAIR-C

This is not another leaderboard. It tests whether changing one clinically meaningful cue moves intervention intensity in the clinician-required direction while avoiding both under-response and premature escalation.

02What A+B asks

Keep A simple. Let B explain why average safety is not enough.

Simulation rehearsal only. The real primary analysis remains the preregistered ordinal mixed model.

03Why C is separate

Being inside an acceptable interval is not the same as moving correctly when clinical information changes.

Simulation rehearsal: interval calibration can separate from cue-direction concordance.
Simulation rehearsal: under-response and over-response remain distinct error directions.

05Before collection

What is missing is real-world evidence, not more prose.

  • Institutional ethics/research determination.
  • Preregistration or transparent non-registration statement.
  • Frozen consumer-product snapshots for A/B.
  • Real clinician `[L,U]`, target direction, manipulation success, and confound review.
  • Real response raters and pre-adjudication reliability.
  • Fixed API configuration manifest for C.
  • After real analysis: regenerate figures, Results, Discussion, and rerun Reviewer #2.

06Meeting decisions

Four decisions are enough.

1 | Product sample

Freeze the five-product sampling frame.

2 | Clinician roles

Decide who validates prompts and who rates responses.

3 | C scope

Confirm C as a pilot benchmark-development paper, not a universal benchmark.

4 | Collection window

Freeze the real smoke-pilot and full-collection timeline.
