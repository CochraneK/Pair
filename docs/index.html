01两篇论文

现在不是 A / B / C 三选一，而是两篇不同层级的论文。

Paper 1｜A + B

A 是主研究：同主题、严格匹配的 psychosis vs control。B 是嵌套的 exploratory substudy：只改变 conviction、insight 或 behavioral risk，观察回应策略是否跟着动。

Paper 2｜PAIR-C

它不做“谁分数最高”的普通 benchmark，而是研究单一临床 cue 改变时，模型干预强度是否沿医生要求的方向移动，同时避免 under-response 与 over-response。

最值得发表的 C，不是得到一个排行榜，而是找到模型“在哪些临床信息上不敏感、又在哪些地方反应过头”。

02A+B

A 的故事越简单越强；B 负责解释为什么“平均安全”还不够。

真实主分析仍是 ordinal mixed model。产品排名、P1–P5、failure profile 和 stability 都是解释层，不应该抢走 psychosis-specific penalty 这条主线。

模拟敏感性结果：5 个产品的 psychosis-minus-control 配对风险差约为 23.8–50.0 个百分点。这个数值只是演练，不是现实产品表现。

为什么要看完整 0–2 分布

平均分会把“部分不恰当”和“完全不恰当”混在一起。正式图应展示 category probability 或 stacked distribution。

为什么要做重复采样

模拟中，同一题三次评分完全一致仅 25%–50%。如果真实数据类似，一次查询会低估随机失败。

05真实采集前

现在缺的是现实世界证据，不是更多漂亮文字。

  • 真实伦理/研究属性认定。
  • 正式 preregistration 或透明说明未注册。
  • A/B 的消费级产品版本、账户、搜索/思考/记忆状态冻结。
  • B/C 的真实医生 [L,U]、target_direction、manipulation success 与 confound review。
  • 真实 response raters 与裁决前一致性。
  • C 的固定 API model/config manifest。
  • 真实分析完成后重新生成全部图表、Results、Discussion，再做一次 Reviewer #2。

06会议拍板

建议会议只决定四件事。

1｜产品集合

A 的五个消费级产品是否就是最终 sampling frame？

2｜医生角色

谁做题目 validation，谁做输出 rating，是否尽量分开？

3｜C 的定位

是否认可它是 pilot benchmark-development paper，而不是一次做成“终极 benchmark”？

4｜采集窗口

什么时候冻结产品快照并完成真实 smoke pilot？

01Two papers

This is no longer a choice among A, B and C.

Paper 1 | A+B

A remains the matched psychosis-versus-control consumer-product audit. B is a bounded exploratory substudy asking whether response policy changes when a single clinical cue changes.

Paper 2 | PAIR-C

C asks whether intervention intensity moves in the clinician-required direction while avoiding both under-response and premature escalation.

02A+B

Keep A simple; let B explain why average safety is not enough.

The real primary analysis remains the ordinal mixed model. Product ranking, P1–P5 profiles and repeated-query stability should remain explanatory layers.

03PAIR-C

Interval calibration and cue-direction sensitivity are distinct properties.

The simulation rehearsal produces high CCA but lower directional concordance. If this dissociation reproduces empirically, it becomes a stronger methods result than a conventional leaderboard.

05Before collection

What is missing is real-world evidence, not more prose.

  • Institutional determination and preregistration status.
  • Frozen product/model configurations.
  • Real clinician [L,U], target directions and validation.
  • Real response ratings and reliability.
  • Frozen analysis followed by regenerated figures, Results and Discussion.
