00为什么开这个会

不是证明学生方案“不行”，而是区分：必须修的、值得增强的、已经变成新研究问题的。

Validity

不修会影响可信度：matched-control 混杂、版本记录、评分信息损失。

Publication ceiling

原研究能做；增强是为了让论文回答更有意义的问题。

New science

一旦研究问题改变，就不应假装只是“优化原 protocol”。

会议的核心不是“换方案”，而是共同决定：原方案做到什么程度、哪些新增问题值得成为共同贡献。

02先替原方案辩护

如果我是审稿人，我不会说这个研究没有价值。

有匹配对照

比单纯模型排行榜更能估计 psychosis-specific penalty。

有临床 taxonomy

SIPS P1–P5 和医生评分提供临床结构。

有现实场景

消费产品是普通用户真正会遇到的界面。

A 不是备胎：它是原学生研究的正式升级版，也是 Paper 1 最稳的主问题。

05APP vs API

A/B 和 C 刻意测两个不同层级，不把“产品”和“模型”混成一个概念。

A/B｜消费产品

base model + hidden system/safety + routing + search + memory/history + quota/fallback + UI。结论只能限定到 tested product/date/configuration。

C｜固定 API 配置

尽量冻结 provider model ID、system prompt、temperature、top_p、reasoning/tools 和日期，回答 configuration-level calibration。

APP 不是低配 API；它回答现实世界暴露。API 也不是“更真实”；它回答更可复现的机制问题。
数据边界：当前题库为 fictional/synthetic research prompts，不使用患者原始临床记录。

06别人做到哪里

查新的作用是剥掉虚假 novelty，而不是证明项目不能做。

方向已有工作已经覆盖PAIR 应怎么避开
Psychosis prompt appropriateness已有直接父本与 psychosis benchmarkA 明确做 replication/extension + 中国消费产品层
Long-context / delusion escalation已有多轮与 harmful histories当前不把“越聊越恶化”当本研究 claim
General mental-health benchmark已有大规模 PsychiatryBench 等不打题量规模战
Safety/calibration已有 over-refusal、uncertainty、risk calibrationC 的组合创新收窄到 psychosis-specific minimal contrasts + interval + bidirectional error

07怎么说服，而不是推翻

会议语气应该先保护原工作，再解释为什么修改是在保护它。

“原来最重要的 matched psychosis vs control 我觉得应该保留。现在主要是把配对、产品快照、评分和统计做得更干净；这些都不改变原 Research Question。”
“如果目标只是稳妥完成一篇，A 已经够。如果愿意提高 publication ceiling，我们再加一个很小、预先限定的 Aim 2，而不是把所有想法都塞进去。”

09为什么现在是两篇

Paper 1｜A+B

现实世界 consumer-product audit。A confirmatory；B 是 6 family 的 prespecified exploratory substudy。

Paper 2｜PAIR-C

方法学/benchmark-development paper。64 prompts 只是 pilot；两水平测方向敏感性，不声称精确 threshold localization。

拆成两篇以后，A 不会被 C 的方法学野心拖垮；C 也不用假装只是原论文里一个“小增强”。

11医生到底要做什么

把临床工作量讲清楚，老师才知道自己是在审核什么。

A｜先审题，再评输出

审 psychotic/control 是否 minimal、自然、文化上合理；输出评 overall appropriateness 0/1/2 + recognition / non-reinforcement / urgency / resources。保留 raw ratings 后再 adjudicate。

variant：manipulation success、confound、第二轴变化、`[L,U]`；pair：直接标 target direction（下降/不变/上升）和 clinically relevant change。模型输出后再盲评 policy y 与 contraindicated behavior。

15什么结果也算成功

研究成功不等于“必须跑出一个特别差的模型”。

研究有价值的结果不要怎么写
A干净、精确地估计 psychosis-vs-control effect；即使 product interaction 弱也有价值不能把最大 OR 写成全球“最不安全产品”
BCCA 相近仍可发现 cue sensitivity、family heterogeneity、stochastic instability不能把 324 次生成当 324 个临床样本
C最有价值的是 static calibration 与 directional sensitivity 分离，或稳定 axis/family failure signature；阴性结果也能反证设计如果只剩平均榜单，不硬包装方法学突破
语言定位：中文是主要应用语境；英文作为 secondary/sensitivity，比把 bilingual 本身当主要 novelty 更稳妥。

00Why this meeting

The goal is not to show that the student protocol is wrong; it is to separate validity fixes, publication-strengthening extensions, and genuinely new science.

The meeting should feel like a shared derivation of the final design, not a replacement plan arriving from nowhere.

01Original study

The original protocol already asks a coherent single-turn question.

It uses 80 psychosis-related prompts across SIPS P1–P5, 80 matched controls, consumer Chinese chat products, psychiatrist 0–2 appropriateness ratings plus four components, and a repeated subset for stochastic stability. It does not establish longitudinal symptom worsening.

02Strongest defense

The core is publishable in principle.

Matched contrast

More informative than a pure leaderboard.

Clinical structure

SIPS taxonomy and psychiatrist ratings matter.

Real-world layer

Consumer products are what ordinary users actually encounter.

03Hard problems

Fix credibility before adding complexity.

The main problems were confounded controls, overclaiming product behavior as base-model traits, weak novelty wording, loss of rater disagreement, and an unfrozen primary statistical framework.

Prompt improvement means making contrasts attributable, not generating more text.

Examples included holding investment amount constant in a grandiosity pair, holding confrontation constant in a suspiciousness pair, and holding medication advice constant in a perceptual-abnormality pair.

05APP vs API

A/B and C deliberately evaluate different strata.

A/B consumer products

Base model + hidden system/safety + routing + search + memory/history + quota/fallback + UI. Claims are product/date/configuration snapshots.

C fixed API configs

Freeze provider model ID and generation/tool settings to support configuration-level reproducibility.

All current prompts are fictional/synthetic research prompts; raw patient clinical records are not used.

06Literature landscape

Novelty search removes weak claims and protects the real contribution.

Psychosis prompt studies, multi-turn delusion work, large psychiatry benchmarks, and general safety/calibration work already exist. PAIR therefore avoids “first Chinese benchmark” or generic “response policy” claims and narrows C to psychosis-specific minimal clinical contrasts + clinician acceptable intervals + bidirectional calibration.

07How to persuade

Protect the original work first.

“The matched psychosis-versus-control question should stay. Most revisions make the pairing, product snapshot, rating process, and statistics cleaner without changing the research question.”
“If the goal is a solid first paper, A is sufficient. If we want a higher publication ceiling, add one bounded exploratory clinical-cue question rather than every possible idea.”

09Why two papers

Paper 1 | A+B

Consumer-product audit. A is confirmatory; B remains prespecified exploratory because only six scenario families are the clinical replication units.

Paper 2 | PAIR-C

Benchmark-development pilot. The 64-item two-level design tests directional sensitivity, not precise threshold localization.

11What clinicians do

A separates prompt review from response rating; B/C establish ground truth before outputs.

A reviewers verify pair validity and later score 0–2 appropriateness and components. B/C clinicians annotate manipulation success, confounds, `[L,U]`, pair-level target direction, and clinical relevance before model outputs are collected. Response raters then score delivered policy and contraindicated behaviors.

Prefer separate ground-truth and response-rating panels; if personnel overlap, freeze ground truth before any output is visible.

15What still counts as success

A clean psychosis-vs-control effect remains informative even with weak product interactions. B can reveal cue sensitivity or family heterogeneity even when average CCA is similar. C is strongest when static calibration dissociates from directional sensitivity or produces interpretable axis/family failure signatures; it should not collapse into a simple leaderboard.

Chinese is the primary application context; English is better positioned as a secondary/sensitivity layer than as the main novelty claim.
