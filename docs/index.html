Paper 2 · C · current master: v2

Psychosis-specific response-policy calibration

PAIR-C evaluates one-clinical-cue-at-a-time minimal contrasts using clinician-defined acceptable intervention intervals [L,U] plus prospectively annotated pair-level target direction.

  • 8 scenario families × 4 axes × 2 levels = 64 prompts.
  • Axes: conviction, insight, behavioral risk, evidence/plausibility.
  • Metrics: CCA, ordinal-step URS/ORS, CDC, Relevant Sensitivity.
  • Nuisance Invariance is not estimated in the current pilot.
  • Two-level contrasts test direction/sensitivity, not precise threshold location.

Paper 2 · C · 当前 Master：v2

精神病性场景 response-policy calibration

PAIR-C 采用“一次只改变一个临床 cue”的最小对照设计，以医生定义的可接受干预区间 [L,U] 和预先标注的 pair-level target direction 评价模型回应。

  • 8 个 scenario families × 4 个轴 × 2 水平 = 64 条提示词。
  • 轴：conviction、insight、behavioral risk、evidence/plausibility。
  • 指标：CCA、ordinal-step URS/ORS、CDC、Relevant Sensitivity。
  • 当前 pilot 不估计 Nuisance Invariance。
  • 两水平对照用于方向/敏感性评价，不用于精确 threshold 定位。
