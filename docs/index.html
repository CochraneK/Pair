Paper 1 · A+B · current working state: Master v4

Consumer-product psychosis audit

Aim 1: matched psychosis-related versus matched nonpsychotic prompts across Chinese-language consumer AI products.

Aim 2: prespecified exploratory minimal-contrast substudy testing whether response policy shifts proportionately when conviction, insight/alternative-explanation acceptance, or immediate behavioral risk changes.

Key safeguards

  • Claims are product/configuration/date specific, not base-model essentialist.
  • P5 disorganized-communication sensitivity analysis is prespecified.
  • Raters are blinded to product identity; prompt condition is not falsely claimed to be blinded.
  • Six Aim-2 scenario families remain exploratory clinical replication units.

Paper 2 · C · current working state: Master v2

Psychosis-specific response-policy calibration

PAIR-C evaluates one-clinical-cue-at-a-time minimal contrasts using clinician-defined acceptable intervention intervals [L,U] and prospectively annotated pair-level target direction.

Current 64-item pilot

  • 8 scenario families × 4 axes × 2 levels = 64 prompts.
  • Axes: conviction, insight, behavioral risk, evidence/plausibility.
  • Metrics: CCA, ordinal-step URS/ORS, Clinical-Cue Directional Concordance, Relevant Sensitivity.
  • Nuisance Invariance is not estimated in the current pilot.
  • Two-level contrasts test direction/sensitivity, not precise threshold location.

Protocol → data → paper chain

The canonical workflow is designed so that prompt versions, collection manifests, ratings, statistics, and manuscript claims can be traced without silently changing definitions after outcomes are known.

Submission gates

  • Real institutional ethics determination where required.
  • Public preregistration or transparent disclosure of non-registration.
  • Exact consumer-product and API/model configuration manifests.
  • Real clinician prompt validation, policy intervals/directions, and response ratings.
  • Frozen analysis, software/session information, and empirical tables/figures.
  • Data Availability, Code Availability, authorship, funding, competing interests, and final CHART audit.

Repository

The repository is the canonical source of truth for public collaboration-safe research state. Binary exports generated in chat (for example DOCX/ZIP working copies) are not automatically mirrored into Git; canonical text, protocol, schema, code, and status files should be kept in Git.
