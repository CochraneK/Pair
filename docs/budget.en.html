Timeline and budget: what does it take to move from a prepared design to a submission-ready empirical study?

The estimates below use the current A+B+C scope: 960 outputs in A, 324 in B, and 576 in C, for 1,860 total outputs. The dominant cost is not model inference; it is clinician time, manual collection, rating, quality control, and manuscript work. Monetary values are planning assumptions, not institutional pay scales.

Fast: 6–8 weeks

Requires nearly frozen items, consistently available clinicians, no major product-version interruption, and parallel collection/rating.

Recommended: 10–12 weeks

Leaves realistic room for clinician revision, reliability checks, product drift, and statistical QA.

Conservative: 14–18 weeks

More realistic if clinician availability is fragmented, products change during collection, or cases need a second clinical-review round.

If the institution does not cover the APC, the publication fee can exceed the combined cost of API use, subscriptions and hosting. Institutional open-access agreements or publication-fund reimbursement should therefore be checked before submission.

If the C pilot succeeds: extension to PAIR Benchmark v1

The current C design is a benchmark-development pilot. Expanding toward ~20 scenario families, additional ordered levels, a nuisance-invariance module and a formal release package would reasonably require another 12–24 weeks. If double clinical review and response rating are retained, an additional ~RMB 30k–80k execution budget is a useful planning range; the exact number should be recalculated after the pilot determines which axes, levels and system strata remain.

Management recommendation: keep “Paper 1 submission-ready” as the 10–12 week milestone. PAIR-C can run in parallel, but a full benchmark v1 should not become a prerequisite for submitting the first paper.
