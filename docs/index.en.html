00Research questions

The project asks more than which model receives the highest score.

Paper 1 asks whether consumer AI products respond less appropriately to psychosis-related content than to tightly matched ordinary controls. Paper 2 asks whether changing one clinically meaningful cue within the same scenario produces a proportionate change in response intensity, without reinforcement, under-response, or premature escalation.

The two papers are linked: the first measures a psychosis-related appropriateness penalty; the second examines whether AI responses are clinically contingent on subtle changes in the scenario.

Each pair is revised so that the intended clinical contrast carries as much of the difference as possible.

Examples include holding investment size constant in a grandiosity pair, holding confrontation behavior constant in a surveillance pair, and holding medication-risk content constant when contrasting auditory experiences with an ordinary source.

04Consumer product vs API

Consumer applications and fixed API configurations answer different questions.

Consumer product

The observed response includes the base model, hidden system instructions, safety layers, routing, search, memory, account state, quota behavior, and interface defaults.

Claim: behavior under the tested product conditions and date.

Fixed API configuration

Exact model IDs and generation settings can be logged and reproduced more directly.

Claim: behavior of the tested model configuration under the frozen request settings.

A/B use consumer-product snapshots; C uses fixed API configurations. These strata are not pooled as one undifferentiated benchmark.

05Literature boundary

The contribution is narrower than “AI and psychosis has not been studied.”

Prior work already covers psychosis prompts, mental-health safety, multi-turn vulnerable conversations, over-refusal, uncertainty, and psychiatric benchmarks. PAIR therefore focuses on tightly matched psychosis-related contrasts, consumer-product reproducibility, and psychosis-specific minimal clinical contrasts evaluated with clinician-defined acceptable response intervals and bidirectional error measurement.

06Two papers

The second paper exists because the added question is methodologically distinct.

Paper 1 — A+B

A: 80 matched pairs across five consumer products, with ordinal appropriateness as the primary outcome. B: a prespecified exploratory substudy using six scenario families and three clinical axes.

Paper 2 — PAIR-C

Eight scenario families × four clinically relevant axes × two levels, tested on three fixed API configurations with repeated generations. The pilot measures calibration under minimal clinical contrasts rather than exact threshold location.

08Clinician workflow

Clinical work separates prompt validation from response rating.

A: validate matched-pair comparability and realism, then rate de-identified prompt–response pairs on 0–2 appropriateness plus component flags.

B/C: validate manipulation success and confounds, define acceptable response-intensity interval [L,U], directly annotate the required direction of change, define contraindicated behaviors, then rate model outputs on the same escalation-intensity scale.

Preferred safeguard: use separate ground-truth and response-rating panels where feasible; otherwise freeze ground truth before outputs are available.

12Ethics & evidence boundary

The study evaluates generated responses, not patient outcomes.

  • Current prompts are fictional/synthetic research scenarios, not patient records.
  • The study cannot establish that chatbot use causes improvement or deterioration in real patients.
  • Psychosis is not equated with violence; the behavioral-risk axis concerns immediate intended high-consequence action.
  • Cultural review is required to avoid pathologizing culturally sanctioned beliefs.
  • Institutional ethics/research determination and actual preregistration remain real-world requirements.
